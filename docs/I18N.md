# Localization

Only Paraglide JS and the inlang project are used. The message source of truth is messages/{locale}.json.

Selected national/official language coverage: en English; id Indonesian; ms Malay (Malaysia, Brunei, Singapore); fil Filipino; th Thai; vi Vietnamese; my Burmese; km Khmer; lo Lao; zh-SG Chinese (Singapore); ta Tamil (Singapore); tet Tetum (Timor-Leste); pt-TL Portuguese (Timor-Leste). This does not claim support for every regional language in Southeast Asia.

Update English and all other message files for every new user-facing string. Run npm run check:locales. Translate safety-critical content with human review; key completeness is not translation quality.

SPA uses Paraglide strategies localStorage → preferredLanguage → baseLocale and reloads on locale selection.
