# Localization

Only Paraglide JS and the inlang project are used. The message source of truth is messages/{locale}.json.

Selected national/official language coverage: en English; id Indonesian; ms Malay (Malaysia, Brunei, Singapore); fil Filipino; th Thai; vi Vietnamese; my Burmese; km Khmer; lo Lao; zh-SG Chinese (Singapore); ta Tamil (Singapore); tet Tetum (Timor-Leste); pt-TL Portuguese (Timor-Leste). This does not claim support for every regional language in Southeast Asia.

Update English and all other message files for every new user-facing string. Run npm run check:locales. The checker validates key and placeholder completeness across all 13 catalogs. A flagged language dialog replaces the native select; mobile quick settings groups language, share and theme. Independent human review remains outstanding, especially safety, install and bot-verification wording; key completeness is not translation quality.

The URL determines the locale. Language selection navigates in place while retaining query and hash. Build-time SSR uses Paraglide's request-scoped middleware; all 13 locale homepages and legal routes are prerendered with localized body content, canonical URLs, hreflang links and Open Graph locale/alternate metadata. A shared fallback remains for offline recovery and unknown client routes.

## Localized editorial routes

The about page, guide index and three explanatory guides (administrative geography, environmental snapshots, and biodiversity/cuisine/destinations) are authored in the 13 `messages/{locale}.json` dictionaries under `editorial_*` keys. They are rendered as escaped text by `EditorialDocument.svelte`; only section headings, safe external links, inline code and emphasis are parsed. Slugs stay stable across languages and links use `pathFor`.

`svelte.config.js` registers the prefixed pages; `scripts/prepare-static.mjs` adds localized canonical URLs, `hreflang`, metadata, JSON-LD and sitemap entries. `scripts/check-editorial-build.mjs` validates the 65 editorial HTML outputs during `npm run build`. `tests/i18n/editorial.test.mjs` checks dictionary coverage and content structure. New editorial copy must update all 13 catalogs, not just English.

These translations have not been reviewed by native speakers, especially the safety-related warning language and technical terms. The linked source documentation is presently in English. Before publishing, review translations, factual claims, mobile readability, SEO output and provider terms.

## Standalone fatal errors and share images

The build regenerates `src/error.html` from `src/error.template.html` and the existing 13 Inlang catalogs by running `node scripts/generate-fatal-error.mjs` before Vite. The standalone error document embeds only translated recovery messages and a small, SHA-256-CSP-authorized inline script. It does not request app JavaScript, fonts, or images. The path prefix determines the locale, and the status selects the 500/503 text. When JavaScript is disabled, the static English message and recovery links remain available, including a specific 503 message in exported `build/503.html`. Do not edit the generated `src/error.html` directly.

Generated share images require a localized `visitLabel` from the caller. All four card variants receive `m.share_visit_cta()`; the low-level canvas renderer must never introduce a hardcoded English fallback.
